# 📊 Financial Performance Dashboard | FY 2025

An end-to-end financial data analytics project built using **Python, SQL, and Power BI** to analyze revenue, expenses, profitability, and budget performance.

The project transforms raw financial transaction data into meaningful business insights through data cleaning, exploratory data analysis, SQL queries, and an interactive Power BI dashboard.

---

## 📌 Project Overview

The Financial Performance Dashboard provides a comprehensive view of an organization's financial performance during FY 2025.

It helps analyze:
- Total Revenue
- Total Expenses
- Net Profit
- Profit Margin
- Revenue by Region
- Expenses by Department
- Actual vs. Budgeted Expenses
- Monthly Revenue and Expense Trends

## 🎯 Project Objectives

- Analyze financial transactions using Python.
- Clean and prepare datasets for analysis.
- Perform financial calculations using SQL.
- Compare actual expenses against budgeted expenses.
- Identify departmental and regional financial performance.
- Build an interactive dashboard using Power BI.

## 📈 Dashboard Features

The Power BI dashboard includes:

1. **KPI Cards:** Total Revenue, Total Expenses, Net Profit, and Profit Margin.
2. **Budget Analysis:** Actual vs. Budgeted Expenses by Department.
3. **Regional Analysis:** Revenue distribution across four regions.
4. **Department Analysis:** Expense distribution across departments.
5. **Trend Analysis:** Monthly revenue and expense trends.
6. **Interactive Filters:** Department, Region, and Month slicers.

## 🔍 Project Workflow

1. Data Collection – Imported financial transaction and budget datasets.
2. Data Cleaning – Checked missing values, duplicates, and data types using Pandas.
3. Exploratory Data Analysis – Analyzed revenue, expenses, departments, and regions.
4. SQL Analysis – Used SQLite to calculate financial metrics and monthly performance.
5. Budget Analysis – Compared actual financial performance against budget targets.
